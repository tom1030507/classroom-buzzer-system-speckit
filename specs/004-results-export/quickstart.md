## 本機手動流程（不需要 Google）

1. `npm start`，老師登入、建立活動、匯入題目（需要真實試算表；只測結果與 CSV 時可沿用已匯入的活動）。
2. 兩個瀏覽器工作階段各加入一組，分別送出不同單位，保留一題無人作答。
3. 老師結束活動：老師與兩組畫面在 2 秒內顯示結果；無人作答的題目明確標示。
4. 重新啟動伺服器，再開啟兩種頁面，結果相同（AC-15）。
5. 老師下載 CSV，以試算表軟體開啟：中文正常、公式開頭的答案前有 `'`、沒有公式被執行（AC-20，附截圖）。

## 真實雲端試算表驗收（需要服務帳戶）

前置：依 README 設定 `GOOGLE_APPLICATION_CREDENTIALS`，把課程範本副本共用給服務帳戶（編輯者）。

1. **AC-12、AC-17**：兩個單題與三題題組分散在兩張工作表。勝出答案含中文、換行、`=1+1` 開頭與 `'` 開頭。
   預覽 → 勾選已暫停編輯 → 寫回。開啟原試算表確認：各答案在原格、為純文字、其他內容與格式不變、無人作答格仍是原標記。
2. **AC-13**：另一場活動匯入後，分別移動一個標記、刪除一列、改寫一格、合併一格、刪除一張工作表。
   每次預覽與寫回都顯示衝突並停止，試算表沒有任何格子被寫入。
3. **AC-14**：寫回中途中斷網路，畫面顯示失敗或「待核對」而非成功；恢復網路後再次寫回，
   已寫入的格子顯示「已是相同內容」。手動把一格改成其他文字後重複寫回，該格顯示衝突且未被覆寫。
4. **AC-02**：換一份版面不同、題號不連續的試算表副本，確認寫回到新位置。

每一步保留截圖與試算表連結。
