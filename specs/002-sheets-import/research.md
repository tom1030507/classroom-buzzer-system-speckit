# SF-02 設計決策

## 雲端讀取（FR-02，AC-01、AC-03）

使用服務帳戶與 Sheets 讀寫 scope，供 SF-04 沿用同一授權寫回。Gateway 用 Node 內建 `fetch` 和 `crypto.sign` 簽署 RS256 assertion，向固定 Google token URL 交換存取權杖，再以 `getByDataFilter` 依工作表 ID 讀取格值、合併範圍與格線資訊。使用工作表名稱作為識別會在改名時失效；只讀 values 無法檢查合併答案格。測試替身驗證請求，真實雲端驗收見 [驗收紀錄](acceptance.md)。

## 標記解析（FR-02、FR-08，AC-02、AC-03、AC-17）

解析 `userEnteredValue.stringValue`，避免公式顯示的文字成為答案格。分開偵測標記候選與驗證正式語法，讓中文輸入法產生的全形大括號及全形 Q 報出原格位。保留符合語法的原始完整文字，供 SF-04 驗證格位未被改寫。

## 預覽與確認（FR-02，AC-03）

暫存預覽綁定教師工作階段與活動，能讓教師確認剛看過的同一份內容。記憶體暫存避免未確認預覽變成持久資料；逾時或重啟須重新預覽。Google 讀取在 SQLite 交易外執行；網路返回及交易內都檢查活動階段，最後以單一交易替換既有資料。
