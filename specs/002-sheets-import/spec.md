# SF-02 線上題目匯入

負責人為 tom1030507。此功能對應 GitHub #5 至 #8，依賴 SF-01 的教師授權。

## 使用者情境

- **US1（#6，FR-02、FR-08，AC-02、AC-03、AC-17）** 教師從答案格內完整的單題或題組標記取得題號及原格位。掃描依工作表選擇順序、列、欄，保留原題號。兩題以上共用題組代號時合成一個單位，以最先出現的成員決定單位順序。
- **US2（#7，FR-02，AC-01、AC-03）** 教師以試算表網址或 ID 指定已分享給服務帳戶的雲端試算表。系統直接取得工作表清單與所選工作表的儲存格、合併範圍及格線結構。網路、權限、不存在、配額與逾時分別回報。
- **US3（#8，FR-02、FR-08，AC-01、AC-02、AC-03、AC-17）** 教師在準備中選擇並排序工作表、檢查題號、題組、題數與原格位，再確認匯入。確認時原子取代前次匯入，學生只取得可作答的題號與單位。資料無效、授權失敗或階段已變更時保留原匯入。

## 釐清

- 去除首尾空白後，儲存格的文字必須完全符合標記語法。含題號標記起始符號卻未完全符合語法的格子視為非法。全形或半全形混用的大括號與 Q 會被辨識為候選，再以正式 ASCII 語法驗證並回報非法格位。原格文字完整保存供後續寫回比對。
- 預覽只在伺服器記憶體暫存，綁定發出預覽的教師工作階段及活動。預覽在 15 分鐘後過期。重啟後需重新預覽，已確認的匯入保存在 SQLite。

## 功能需求

- **FR-02（AC-01、AC-03）** 教師登入後可直接從已授權的 Google Sheets 讀取工作表及格位。準備中才可取得預覽和確認，確認整批取代，操作失敗須保留舊資料並指出原因。
- **FR-08（匯入，AC-02、AC-03、AC-17）** 單題和題組成員依教師指定表序與格位掃描。跨表同題組至少兩題，題號在活動內唯一，答案格不可合併。

## 成功標準

- **AC-01** 以真實雲端表單匯入五題，核對題號、數量與來源格位。
- **AC-02、AC-17** 在不同版面與非連續題號下，兩個單題和跨表三成員題組形成五題、三個有序作答單位。
- **AC-03** 無權限、網路失敗、非法標記（包含全形樣式）、合併格、重複題號或單成員題組均回報錯誤，先前匯入保持完整。測試替身與真實雲端驗收的證據分別記在 [驗收紀錄](acceptance.md)。
