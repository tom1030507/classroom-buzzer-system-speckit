負責人：tom1030507。對應 GitHub #9、#10、#11、#12。

## 使用者情境

- **US1（#10，FR-03，AC-04、AC-10、AC-15）** 教師在匯入至少一題後開啟，再確認結束。已連線者在本機兩秒內收到階段更新。重連從 SQLite 取得最新快照。結束及受理使用同一交易序列。
- **US2（#11，FR-04、FR-08，AC-05～AC-08、AC-18）** 學生每次提交一個完整單位。伺服器原子地檢查階段及身分、去重、分配受理序號和保存原文。重送取得原受理紀錄。
- **US3（#12，FR-05，AC-05、AC-09、AC-16）** 教師看各組的已送出狀態、答案、受理順序及暫定勝出組。公平模式顯示「結束時計算」。學生看題號與自己的受理資料。頁面、HTTP 和 SSE 都以工作階段過濾，答案一律為純文字。

## 釐清

每題上限以 Unicode code point 計算。全形空白也屬空白。原文和換行保留；無法忠實編碼為 UTF-8 的未配對 surrogate 會拒絕。學生受理識別使用不含內部受理順位的不透明 ID。
